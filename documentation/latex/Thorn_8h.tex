\doxysubsection{Detailed Description}
\doxylink{classThorn}{Thorn} trap class with rotating damage directions. 

Trap object that can damage entities in specific directions. Directions rotate each turn, creating dynamic hazard patterns. Deals damage to the player when interacting if the thorn is directed at him.
